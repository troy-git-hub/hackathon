# 基础版：主页、复习小册与黑板聊天

更新：2026-11-15。此轮是工作区基础功能，不改变已公开的 2.4.0 下载；内测/高级版发布由另一会话统一处理。

## 已完成

- 主页横向布局：左边命名与开始课堂，右边复习小册；下面六张功能卡两列排列。空数据时保留位置和引导；小屏限制宽度，长内容可以滚动。
- 课堂页增加「复习小册」。主页可管理已有小册；课堂入口默认勾选当前知识点，另可选择历史课程知识点，按自定义大类整理。
- 小册保存为 `paths.config_dir()/booklets.json`，跨课使用；来源快照独立保存，所以原始历史课程删除后仍可读。可离线保存摘录，或一次 AI 请求生成主线、章节、来源、自测问题及参考答案。
- 「我的」资料页可直接打开设置；知识库入口放到设置，主页移除原有课前资料库长按钮。保留另一会话新增的账户、同步、更新和日志入口。
- 设置的课堂 AI 频率：积极（共享间隔20秒、知识分析25秒）、均衡（35/40秒）、节省（50/60秒）。下次开课采用新预设。无新转写不分析，同一时间共享预算，不是每次界面刷新都调用模型。

## 黑板

- 主 AI 的知识点输出增加 `board_needed`、`board_focus`。只有实质性新知识主线或重要新关系才请求板书；重复解释、摘要换词、补一句例子不新增。旧模型没返回新字段时，新主题可生成一次。
- 自动板书去重键改为稳定 `board_focus`，缺省为知识点名称，不再把摘要文本纳入去重键。
- 新增第四页「聊天」。输入问题后展示用户问题与 AI 的明确答复，必要时再更新板书，并按真实内容差异列出“第几节/图解/易混点”等跳转入口。
- 聊天修改当前板书采用原位修订，保留原 `created` 标识并递增 `revision`，不因追问反复新增历史编号。普通聊天可以 `update_board=false`，只回复，不改变板书。
- 聊天可通过 `reply_html` 内嵌安全 HTML。保留近期对话、当前展示板书的章节文字和来源；历史板书来源追加独立 P 前缀，避免与当前讲解来源 ID 冲突。
- HTML 沿用已有沙箱。新增蓝/橙/绿绘图变量与柔和背景；比例关系建议用有文字标签的条形、点线或坐标图解释。聊天最多激活一个浏览器图解，较早图解可点击重新展开。
- 历史下拉框改为 `EchoCombo`：非系统菜单、圆角裁剪、主题选中色、更大的行距；截图中的紧密原生下拉列表已替换。

## 数据与接口

小册记录为对象列表：`id/title/category/topics/intro/chapters/sources/mode/created_at/updated_at`。章节含 `title/body/source_ids/question/answer`；来源含 `id/topic/topic_id/category/label/text`。来源可能包含所选课堂转写片段或已有板书摘要，不包含原始录音、截图或模型密钥。基础版保存本地；高级版是否纳入云同步由同步契约明确决定，不自行上传。

调用用途：小册 `purpose=booklet`；板书和深入演示 `purpose=blackboard`；知识点分析 `purpose=classroom`。账户模式的直接视觉请求另附 `extra_body.echo_purpose=blackboard`；个人 API 模式不增加该字段。
