# 字幕、截图与后台 AI（2.3.0）

- 课堂页「字幕」按钮打开独立置顶字幕，拖动空白处移动；A−/A＋调整字号，×关闭。开关与字号会记住。只在上课时显示，新课不会显示旧课字幕。字幕来自本机 Whisper 转写，有识别与断句延迟，不额外调用大模型。
- 黑板区域截图与「圈课件」共用窗口排除：Windows 10 2004 / 11 使用 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)`，只在截屏事务内设置并还原原值。Echo 仍在桌面上，截图显示其背后的课件。接口失败或旧系统会短暂隐藏不支持的窗口，再无激活恢复，避免 Echo 挡住图片。截图排除不影响批注，用户画下的笔迹仍会附到发送图片。
- 知识点抽取、自动板书、自动重点捕捉、自动课堂抽问共用每课的后台调度，自动任务起点至少间隔 50 秒。字数达到 400 不再提前绕过；失败任务也经过间隔。各任务按等待顺序获得机会，未再等待的任务会过期，避免阻塞课堂。
- 无新转写不做知识点分析；同一已生成知识点不重复生成板书。启用截图重点捕捉时，暂停并行的文字自动板书；重点判断在本地复用知识点和强调词，不再单独询问模型。截图之间仍至少 90 秒，每课最多 12 块。自动更新正文不会顺带生成一份新的完整演示；用户打开「演示」或主动重试时才生成。
- 主动提问、点击「我掉队了」、主动出题、结束课堂复盘不需要等自动调度。厂商不支持 JSON 模式时，兼容回退可能产生额外 HTTP 请求，因此 50 秒约束指自动任务调度，不是所有网络请求的硬限速。

上下文在本地裁剪，不额外让模型总结：近期原话最多约 6500～8500 字，时间轴保留开头、近期知识点和未解决断点；黑板携带当前主题、上一块板书的主题/疑问/摘要，以及知识库检索结果。追问保留最多四组完整问答、约 6000 字；历史图片不重复累积，本轮只发送一次当前图片。旧信息省略时会标记，模型不得把摘要当作新增事实。

实现依据：[Microsoft SetWindowDisplayAffinity](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)。具体截屏路径必须实测；本项目自检用覆盖色块验证「窗口可见、截图为底层内容」，并验证排除设置还原和不支持时的隐藏恢复。
