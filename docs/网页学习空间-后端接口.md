# 网页学习空间：后端与运维交接

2026-11-16。用户入口 `/user#study`、`/user#materials`、`/user#exams`，API 前缀 `/api/account/me/study`。原知识点复习、课堂记录和账户功能继续保留。

## 实际学习流程

上传自己的课件或试卷，免费提取文字并校正；用户主动确认后才请求 AI 解析。解析提要、知识点、原题、参考答案和解释可展开检查，AI 推导答案标识来源；再次确认加入题库后，知识点同时进入原复习页面。已有题库可免费组成每日小题、整卷考试和错题重做。

每周考试安排是北京时间的站内待办提醒，不提供离线或邮件推送，不在后台自动生成付费试卷。每日一份小题任务，默认3题，可设1至5题；再次打开会恢复同一份任务。考试题量5/10/15/20，时长5至120分钟。

## API

| 路径 | 方法 | 用途 |
| --- | --- | --- |
| 根路径 | GET | 学习偏好、限额、实时token单价、待办、统计与可用知识点 |
| `/preferences` | GET/POST | 读取或合并保存每日题量、每周考试时间、题量/时长及专注模式 |
| `/materials` | GET/POST | 列表/上传；JSON `filename,content_base64`，可重复上传去重 |
| `/materials/{id}` | GET/DELETE | 私有详情或删除原件、解析和关联题库 |
| `/materials/{id}/download` | GET | 仅所有者下载原件，附件响应并禁缓存 |
| `/materials/{id}/text` | POST | `text`，免费校正、清理旧解析和题库 |
| `/materials/{id}/analyze` | POST | `request_id`，手动调用文字或视觉模型；先预留再结算 |
| `/materials/{id}/confirm` | POST | 免费确认解析题目，幂等加入题库和知识点复习 |
| `/daily` | GET/POST | 查询/开始当天小题；默认免费抽题，只有显式 `generate:true` 才调用AI |
| `/exams` | POST | `request_id,title,knowledge_ids,material_ids,count,duration_minutes,generate,anti_cheat` |
| `/attempts` | GET | 最近50份试卷/每日小题，包括分数、待批题量、错题数 |
| `/attempts/{id}` | GET | 所有者读取试卷，超时自动以已保存答案交卷 |
| `/attempts/{id}/answers` | POST | `answers,revision`，乐观锁防止跨标签页静默覆盖 |
| `/attempts/{id}/submit` | POST | `answers,revision`，一次交卷；重复返回原结果 |
| `/attempts/{id}/retry` | POST | `request_id`，免费创建错题/未答题新试卷，原记录不变 |
| `/attempts/{id}/grade` | POST | `request_id`，手动付费批改待判主观题，防止重复扣点 |
| `/attempts/{id}/events` | POST | 专注模式的失焦、离开、退出全屏记录，不代表系统级监考 |

题型为单选、多选、判断、填空、简答。选择答案从0起，多选用整数数组；文本答案为字符串。选择题本地客观判分，填空与参考文字归一化后相同可判对，否则保留待批；简答待批。交卷前不返回参考答案或解析，交卷后提供结果与参考。试卷截止时间由服务器决定，客户端计时器不决定是否超时。

## 容量和成本边界

- 单文件3MiB，图片1MiB；PDF最多20页，文本提取最多30000字。
- 每次AI分析最多前12000字、最多20道完整题；剩余内容需拆分后处理，结果明确显示范围警告。
- 扫描PDF不会自动付费OCR，可粘贴已识别文字或拆成单页PNG/JPEG，手动请求视觉解析。PDF/DOCX图形、复杂公式可能不随文字提取，应核对原件。
- 每账户10份资料/原始文件10MiB，全站原件40MiB；文件以账号和资料ID绑定的AES-GCM加密保存，不放公共静态目录。
- 每账户题库600题、试卷200份；全站题库3000题、试卷1000份。保存前检查磁盘空间并为现有备份保留余量。
- 每账户AI学习任务最多15次/天。AI解析、每日新题、整卷出题、主观批改各有用途记录，使用现有token价格、预留与实际结算；无效输出或失败返还预留。
- 页面加载、计划保存、抽取已有题目、客观判分和错题重做均不调用模型。题库不足返回409，前端不能自动改成付费生成。
- 不明确超时使用原request_id重试。资料解析的成功结果可从材料存档恢复，避免短缓存过期后再次扣费；已经失败的请求返回明确可重新开始的状态。

## 文件解析与部署

解析器是独立Python子进程，隔离执行环境并移除业务密钥环境变量；Linux设置96MiB地址空间、8秒CPU与12秒墙钟超时。全站最多一份正在解析、两份上传请求，阻止超限文件占满当前小实例。DOCX不解包落盘，不执行宏或外部实体。JSON请求按流计数，未登录上传在读取正文前拒绝。

依赖 `pypdf==7.1.0`、Pillow；Docker复制 `study.py`、`study_models.py`、`material_parser.py`。账号服务仍为原9090端口和192MiB容器限制，Nginx仅对学习资料路径放宽至5MiB，其余路径保留原限制。SQLite新增4张study表，未替换已有用户数据。

## 本轮验证

- 原账户、发布管理与学习首轮合计52项回归通过；补充后学习专项19项通过。
- 前端模拟API检查包含三路由直达、登录/登出、零自动AI调用、资料确认、五题型、串行自动保存/冲突恢复、交卷/主观待批、免费重做、390px布局。
- 服务器真实端点使用一次性测试账号验证上传去重、Linux PDF解析、答案隐藏、revision、判分、免费错题重做、每日任务幂等和计划保存，随后删除测试账号与资料。
- 本轮没有调用真实模型，没有向外部邮箱发送测试邮件；AI接口验证使用模拟响应，因此不把模拟验收当成真实模型解题质量保证。

已有桌面安装包版本未在本轮重新打包。新网页功能与后台共用账号；桌面同步的知识点可在网页使用，网页原件及整卷试卷尚未作为文件同步到桌面。
