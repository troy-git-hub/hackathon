# Windows 图解代码工作区

2026-11-22，源码与隔离验收完成，未打包发布。

## 操作

黑板先显示一个图解，再点“图解代码”。支持当前板书内图解、演示以及当前聊天中的图解。左侧原生 QPlainTextEdit 查看和编辑 HTML/CSS/JS，右侧复用现有 HtmlLesson 隔离预览，不嵌入整页网站。

- 手改后预览：本机操作，不调用模型。
- AI 写图解 / AI 读代码：一次文字请求，先直接回答学生；可选返回完整替换片段。
- AI 看画面：代码须已预览并加载完成，只截这一块渲染视图，连同代码发一次视觉请求。用户有未预览编辑时拒绝发送，避免拿旧图说成新图。
- 采用到黑板：显式将当前已预览内容写回原图及当前内存板书历史，更新板书 revision。AI返回的代码先留在工作区，不自动替换原板书。

使用设置中的文字/视觉模型，Echo账户模式走原生 `/v1/echo/inference`、`echo.inference/2`，用途 blackboard、max_tokens=3500；文字65秒/视觉115秒。每次AI操作先说明并确认用量，不自动发请求或换模型重试。未知传输结果的手动同内容重试保留 request_id；已拿到结果后不把之后的主动请求冒充未完成任务。

## 限制与保护

提示要求曲线、动点、轴刻度共用求值函数和投影，禁止仅读代码却声称看了实际画面。模型输出 reply 必须存在，html可选、最多12000字符；截断或格式错误保留原代码。源码最多16000字符进入AI；较长原图仍可手动查看/预览，不静默截断后替换。

复用无持久存储 WebEngine profile、opaque iframe、无网络/文件/导航/下载/Python桥/权限的现有隔离视图。预览前拒绝外部资源、iframe、系统/存储接口等明显不支持内容，SVG标准命名空间允许。代码执行仅在此受限网页渲染进程内，不执行 Python、shell 或本机命令。范围检查不等于数学正确性或任意恶意JavaScript的静态安全证明。

捕获账户令牌且前后校验；旧账户不能打开新会话中的旧黑板源码。编辑代码或要求/重新预览后不采用旧AI结果；原板书/目标图解版本变化后禁用AI和写回；换号清空代码、回复与预览并关闭。模型回包按账户核对，不显示其他账户内容。
