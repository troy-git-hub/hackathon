# 用户中心：网页与本地共用学习摘要

2026-11-16。本轮保留 Echo 皮肤和主页布局，扩充个人学习摘要；管理入口仍只在设置中。

## 数据

新增只读 `GET /v1/me/summary`，经现有会话认证，只查询当前账户。网页用户中心和本地账户中心共用它，不调用 AI，不生成额外扣费记录。

- 云端试卷/每日小题：已交卷数、进行中、已到时待交卷、已提交题次、待回顾题次、待主观批改题数。
- 已批试卷均分、最高分和已批卷数。包含待批题目的试卷整体不参与均分，避免未批改的0分误导。
- 已保存资料、清卷原卷、已确认题库题目数量。
- 最近三张试卷/每日小题及状态；网页可直接继续原有答题流程，不重复生成、不调用模型。
- 七日已提交题次折线。按试卷创建日归组，采用北京时间；不是“提交当天”或全天实时学习时长。
- 七日成功 AI 请求数、输入/输出 token 与已结算学习点，失败和处理中请求不计入已消耗学习点。
- 本账户云端逻辑占用，注明实例共享128MiB额度，不伪装为每人独享128MiB。

只统计当前保留的学习空间试卷/每日小题记录；重做是新的题次，不称为不重复题目总数。不把旧版单题练习、本地未同步考试或听课时间编造成这些数字。原有知识点、复习目标和课堂摘要保留。

## 本地

个人中心增加紧凑的四块概览、原生绘制的七日折线、最近试卷。新增云端试卷/错题及清卷入口，使用之前的不落盘登录会话；关闭云端窗口后刷新摘要。管理功能不移入个人中心。不同账户、退出登录后清除摘要与图表；旧服务端缺少新接口时保留其他摘要并提示部分失败。

本轮本地源码更新，不替换官网正式/内测安装包。

## 网页

概览增加个人学习卡片及最近试卷快捷继续入口。手机自动改成单列。修复官网首页移动导航的样式进入控制台后覆盖退出按钮的问题。刷新摘要只读API，页面不自动调用收费模型。

## 验证

后端67项隔离测试通过，包括新摘要的空账户、权重成绩、待批排除、七日费用范围和跨用户隔离。六套本地皮肤检查通过；网页检查覆盖七日图、继续试卷、手机宽度、账户变更与退出清除。预览使用模拟账户与测试数据，不是向真实账户写入的学习记录。
