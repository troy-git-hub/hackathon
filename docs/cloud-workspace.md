# Echo 云端学习空间与本机测试版

## 使用入口

- 网页用户中心：`https://echo.xhbtroy.cn/user`，侧栏分为空间概览、学习分析、复习计划、在线练习、云端数据、账户与用量、账户设置。
- 管理员：`https://echo.xhbtroy.cn/admin`，分为运行概览、用户管理、邀请码与兑换码、邮件服务、API 用量、操作审计、安全设置。
- 本机测试版：运行项目根目录 `Echo-Test.cmd`。没有构建或发布新安装包，官网 Windows 下载仍是原来的 2.4.0。

## 同步规则

本机测试版启动时优先登录。可明确选择跳过，跳过后仅使用自己的模型 API，不使用账户 AI 或云端同步；本地听课和复习仍保留。登录页说明默认同步范围，并允许关闭。登录用户也可以在高级设置使用自己的模型 API，自动同步与模型选择独立。

登录后默认同步 `echo.learning-profile` 2.0.0 的个人资料、知识掌握、薄弱点、复习进度和学习偏好。只上传导出模块的白名单数据，不上传 API 密钥、录音、截图、原始课件、完整课程原文或 HTML。课堂功能继续在桌面端运行。

后台每 15 秒检查本地文件变化；变化后至少间隔 20 秒安排同步，稳定时约每 2 分钟拉取云端复习进度。网络失败保留本地数据，后续重试，不阻塞课堂。可在桌面用户中心立即同步、暂停本机同步，也可在网页设置暂停整个账户同步。

每个账户最多 5 台设备，各自保存最新快照；每台最大 1 MiB，所有学习快照和手动档案合计限 64 MiB。服务器使用 AES-GCM 静态加密，密钥保留在服务器私有配置内，不是端到端加密。仍执行每天备份、最多 7 天的备份保留策略。

设备 ID 和本机资料绑定的账户 ID 保存在 `cloud-sync.json`，文件不保存会话令牌。会话继续保存在操作系统凭据库。首次同步关联当前账户；之后换账户不会自动把旧资料上传到新账户，须在桌面用户中心明确确认归属后重新关联。网络请求固定使用发起时的会话，服务端再检查 `account_id`，防止切换账户时串号。

每台设备独立递增版本；重复内容不创建新版本。版本不符返回 409，客户端下次先读状态再重试，不盲目覆盖。跨设备知识点按 ID 合并，课程数采用快照最大值，避免重叠记录重复累加。相同知识点的课程指标以最近同步的设备快照为准；复习进度按复习时间采用较新记录。

网页自评和答题会更新云端复习进度。桌面端拉取后，只合并更新的复习记录，保留本机已有的课程上下文和较新的本地复习。旧的本机复习格式没有学科字段；跨学科同名知识点的复习保留在网页并显示提示，避免错误覆盖。完整课堂历史与原始资料没有自动下载或恢复功能。手动上传的 JSON 是档案备份；最新一份也参与网页分析。

## 网页分析与练习

分析使用实际同步的知识点、状态、学科分布和网页复习记录，不生成虚假的分数或活跃图。规则指标和自评不等同考试成绩。图表统计的是近七天的网页复习，按北京时间计算。

免费自评有“还是没懂 / 有点模糊 / 记得清楚”三档，分别安排 1 天、3 天或 7/14/30/60/120 天阶梯复习。复习、答题提交使用唯一请求号去重。

AI 练习按知识点生成四选一问题，生成成功消耗配置的学习点，提交答案不再扣点。出题前预扣；超时、模型失败或题目格式不完整返还。服务端加密保存参考答案，作答前不返回答案和解析；作答后服务端判分，同一题不可换答案刷结果。AI 题目和解析可能有误，需要结合教材核对。错题回到复习计划。当前练习历史显示最近 100 题，题目保留 90 天。

## API

同源网页使用 `/api/account/`，原生客户端使用 `https://api.echo.xhbtroy.cn/v1`。

- GET `/me/workspace`：合并后的分析、复习、设备和练习历史。
- GET/POST `/me/sync`：拉取同步状态或提交设备快照。提交格式为 `echo.sync/1`，必须包含与会话一致的 `account_id`、UUID `device_id`、`base_revision`、`profile` 和 `consent:true`。
- POST `/me/review`：知识点 ID、三档结果、UUID 请求号。
- POST `/me/practice`：知识点 ID、UUID 请求号；GET `/me/practice/{id}`；POST `/me/practice/{id}/answer` 提交选项下标。
- POST `/me/preferences`：显示名称、每天复习目标、账户同步开关。
- GET `/me/sessions`；POST `/me/sessions/revoke-others`：查看有效会话并退出其他设备。
- DELETE `/me/devices/{id}`：删除设备快照，本地文件保留；自动同步未暂停时下一次会重新上传。
- GET `/admin/workspace`：仅管理员可看的聚合运行统计，不包含用户学习正文。

接口验证会话、CSRF、自身账户与数据归属；同步与出题分别限流，学习分析同时最多整理一份数据，账户 AI 全站最多 8 个并发。没有开放匿名模型代理，也没有把服务商模型密钥交给客户端。

## 验证

31 项账户测试通过，包括设备版本、账户隔离、暂停同步、自评去重、答案隐藏、服务端判分、重复请求只扣一次、无余额自评和出题失败退款。8 项隔离的桌面同步测试通过，覆盖默认上传、无变化不重复上传、换账户暂停、请求中切换账户、断网、云端暂停及较新复习合并。桌面登录/凭据库和导出测试通过。

使用可自动清理的虚构账户通过公网 HTTPS 验证同步、复习回传、真实模型出题、重放不重复扣点和判分。浏览器使用虚构示例验证侧栏分区、分析表、作答和解析；测试数据随后移除，没有上传用户真实学习文件。
