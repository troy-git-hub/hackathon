# Windows 清卷本地工作台

2026-11-21，本轮交付为本机源码与隔离验收；没有重新打包或发布桌面安装包。

## 从哪里打开

- 主页展开“更多”→“清卷 · 本地出卷”。
- 原生“试卷与练习”窗口右上角“清卷 · 本地出卷”。原有账户云试卷与作答入口保留。
- 设置 →“AI 调用与用量”，可按“清卷”筛选服务端用量。

请使用安装了 `requirements.txt` 的运行环境；本机项目环境为 `.venv/Scripts/python.exe main.py`。本地分页预览依赖 PyQtWebEngine，缺少组件会给出提示，不会跳转网站代替工作台。

## 命题与编辑

命题蓝图包含整卷/专项、学校、卷名、学科、年级、册别、考试名称、考试时长、目标总分、范围要求、审校策略，以及每大题的题型、题量、每题分值、难度、知识点与配图覆盖。支持12种题型：单选、多选、判断、填空、简答、计算、解答、作文、阅读、完形、实验、作图。上限与服务端一致：12个大题、40个主题、阅读等子题合计60小题。

顶部突出“AI命题”，支持 Ctrl+Enter；左侧按试卷信息、题型结构、命题要求分组，每大题为可编辑卡片。卷名、学科、年级、学期、考试类型可选择也可自行填写。新建默认有100分完整数学蓝图；选择学科/用途后可一键套用10学科的整卷或专项结构，另有选择、阅读、写作专项。套用仅更新蓝图，已有卷稿在明确命题前保留。

工作台为独立Windows任务栏窗口，使用Echo图标及窗口身份；右上角可最小化和切换置顶。其他子窗口仍只有关闭。

可以手动建立待编辑卷稿，也可以点击 AI 命题。离线占位题不能直接定稿。题目树和预览点击均可定位题目，支持题干、选项、答案、解析、材料、作者、写作要求、作文格、作答空白和结构配图编辑；阅读子题单独编辑。可移动、增删、撤销最近五次题目变更，并手动 AI 重出或配图。

未应用的编辑按题号保存为本机编辑草稿；切换题目或重开窗口后恢复。应用前不会混入预览、命题或导出，导出/定稿会要求先应用或放弃。正式卷稿采用原子写入，保存失败保持原有文件。定稿后编辑区锁定，需要“另存草稿”继续修改。

人工核对与 AI 辅助审核均保留。选 AI 审核策略时，需手动触发审核，处理问题后才能定稿。修改卷稿会让旧审校失效，不拿旧版审核冒充新版审核。

## 本机试做与批改

“本机试做”为非计时练习，答案与结果保存在本机，不调用云试卷 start 接口。提交前隐藏答案与解析；单选、多选、判断自动判分，多选完全匹配计分。填空及其他主观题显示待批改，不当作已经判错。

提交后可返回工作台，对已作答的主观题手动调用 AI 批改；客观判分和未作答项不会为此调用模型。主流程不要求粘贴JSON。“网上作答”打开考试站查看云端试卷，本机卷稿不会自动上传。参考答案、AI 审校和批改都需要人工核对，不能作为无误保证。

## 本地排版与导出

本地预览复用项目清卷排版器、结构图形渲染和 KaTeX：公式、字体和配图不从 CDN 加载，也不嵌入网站登录或管理代码。预览使用无持久化的 WebEngine profile，拦截远程访问和非白名单本地文件。

预览禁用浏览器默认英文右键菜单。编辑刷新合并，在现有页面更新卷面并保留题目选中/阅读位置；未应用编辑草稿保存不刷新卷面，重复内容不重载。函数图附带本地安全表达式解析器，曲线裁剪在绘图区。本机作答输入合并写盘，提交/关闭前强制保存。

配置包含正式/现代/小学/英语模板、黑白/彩色、密度、A4/16开、单双栏、选项列数、装订/密封线、考试说明、卷头分数栏、大题得分栏、分卷、作文格、答案页题干、答题卡提示、卷头字段、水印与页脚。

右上角选“试卷 / 答案与解析 / 答题卡”后，可导出：

PDF与HTML在“导出”菜单；JSON导入/导出收在“更多 / 高级”，不占据常用操作区。

- JSON：`schema=echo.qingjuan.paper/1`，字段为 `paper`、`config`、`layout`。`paper` 延续清卷 `meta/sections/questions` 格式，包含参考答案和解析供继续编辑。可再次导入，不含账户令牌、请求缓存或本机试做答案。
- HTML：自包含公式字体、排版器与图形，离线可打开、打印，不依赖网络资源。“试卷/答题卡”视图连同页面数据源一起剔除参考答案和解析；“答案与解析”视图保留，便于分开交付。
- PDF：等待当前版本公式、字体和分页完成后导出；通过内容摘要标记避免把上一版预览误导出。纸张尺寸与所选排版一致。

## 存储、账户和云端边界

卷稿保存在 `paths.config_dir()/qingjuan-local/<账户ID的SHA256>/<卷稿UUID>.json`；未登录时使用独立访客目录。账号目录不自动合并，切换账户后旧窗口隐藏内容并停用。导入到另一账户需用户明确导出/导入。

本机卷稿包括蓝图、排版、题目、编辑草稿、有限历史、试做与审校结果及请求元数据，不存模型密钥或会话令牌。

只有用户确认 AI 操作才请求 Echo 云端。整卷命题先检查 `/v1/qingjuan/capabilities` 必须返回 `local_storage:true`，再以 `storage:local` 调异步命题，按原 UUID 查询结果；不支持、失败或过期均不回退成自动保存云卷。成功领取先原子保存本机副本，再交给界面校验。生成后结果在服务器保留10分钟，过期不自动重生成，已有本机副本保留。

单题重出与配图复用原清卷接口，审校与主观批改走受控账户推理。所有相关请求用途为服务端认可的 `qingjuan_generate`，中文显示“清卷”。设置用量表展示服务端 token、学习点和完整 request_id；该编号可与本机卷稿 requests/pending 元数据关联。客户端不乘计费倍率，不猜测扣费。通用推理成功产生 token 后，仅本地结果校验失败不意味着自动退款。
