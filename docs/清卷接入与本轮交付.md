## 用户路径

1. 网页清卷可以导入原项目导出的 JSON，免费保存、预览、打印、下载、开始作答。
2. 生成试卷须明确学科、年级、知识范围、题量和时长，并确认学习点消耗。接 Echo 账户默认文字模型，不接受客户端提供上游密钥。
3. 拍卷通过系统相机/文件选择器，支持旋转、预览、缩放和 JPEG 压缩。上传优化照片移除 EXIF，原照片仅留在选择它的设备内存。
4. 上传免费，视觉解析需要另一次用户确认。结果进入“资料与试卷”，核对并确认后才纳入知识点、个人题库与复习计划。
5. 网页与本地 Echo 的清卷使用同一账户、同一服务端作答记录。已开始的考试保存独立快照，删除原卷不删除已存作答。
6. 客观题自动判分免费；主观题按原学习空间流程单独确认 AI 批改费用。清卷原分值按比例换算成百分制。专注模式仅提供全屏提示与切屏记录，不承诺系统级防作弊。

## 接口

- `GET/POST /v1/me/qingjuan/papers`：私有列表/导入保存。
- `GET/DELETE /v1/me/qingjuan/papers/{id}`：本人查看/删除。
- `POST /v1/me/qingjuan/generate`：显式付费命题；UUID 请求编号用于重复请求保护。
- `POST /v1/me/qingjuan/papers/{id}/start`：免费创建作答快照；同一编号不能复用于另一张卷。
- 继续复用 `/v1/me/study/attempts/{id}` 的服务端期限、答案版本、保存、提交、错题重做与主观批改。
- 官网同源代理前缀 `/api/account/me/qingjuan/`；上传 JSON 上限 512 KiB。每人最多40张清卷、每卷60道实际小题；AI生成5/10/15/20题；考试5–120分钟。

## 额度与资源

- 现网通过有审计的管理员计费接口将输入调为每1000 token 1学习点、输出每1000 token 2学习点。约1000输入+500输出=2点。保留真实供应商 token，未固定按次扣费，既有余额不换算、不扣除。
- 按请求开始时费率结算；供应商未返回 usage 时标记估算；失败退回预留额度。
- 实例私有资料、学习档案、设备同步和清卷原卷共用128 MiB逻辑容量。不是为每个账户预留128 MiB磁盘，也没有声称当前物理磁盘扩容。资料单文件、图片、数量、解析资源仍有单独限制。
- AI共享每日15次学习空间操作上限、全站分钟限流和并发上限，打开页面/刷新/已有卷答题不调用模型。
- 当前邮件系统仍受服务器磁盘和SMTP投递条件限制；未安装正式 Roundcube/Userli 邮箱、未切MX，不能把旧测试页称为完整邮箱。
