# Echo 更新后台

管理入口：https://echo.xhbtroy.cn/admin#releases

当前正式安装包 2.4.1，内测安装包 2.5.1。正式下载不需要账号；内测需要登录，账户有同一套注册邀请码的资格。内测与正式版的安装目录/AppId/数据目录分离。

后台可查看已发布和候选版本、安装包大小与 SHA-256；可激活已签名候选版本，以及暂停/恢复更新信息分发。暂停不删除安装包，不阻止官网直接下载。每个接口独立验证管理员权限，发布记录写审计。

私钥只在开发电脑使用。新版本先在隔离快照构建、安装/卸载验收，离线生成签名清单，经 SSH 上传安装包和 candidates 目录中的清单。后台发布时重新校验 Ed25519 签名、实际文件大小和完整哈希，拒绝降级、同版本不同文件与非法路径。网页不接受任意远程下载地址，也不收私钥。正式清单使用 release/signature 信封；内测清单在顶层携带 signature。

安装版在“设置 → 更新中心”检查，自动检查可关闭。自动检查只通知新版本，不擅自安装；下载后仍需确认，下课后再安装。正式客户端只使用 stable，新的内测客户端通过登录凭据访问 /v1/beta/update 与 /v1/beta/download。源码开发版不检查、不下载、不安装更新。

旧正式 2.4.0 默认地址是本机，第一次可从官网下载2.4.1，或在旧版设置改为 https://update.echo.xhbtroy.cn。旧2.5.0便携内测需要先手动安装新的2.5.1，之后走新的认证内测更新通道。

快速完整目录更新尚未分发：真实构建的 tokenizers/models 依赖目录触发严格过滤，不能删除依赖或跳过安全校验强行发布。本轮使用签名安装包更新，已完成篡改/取消/课堂保护/安装验收。不能把目录更新称为二进制增量补丁。
