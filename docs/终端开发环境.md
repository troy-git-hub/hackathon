# Echo 终端开发环境

## Android（已安装）

- Android Studio 2026.2.2.9：`D:/Android/AndroidStudio/bin/studio64.exe`，开始菜单已有快捷方式。
- Android SDK：`D:/Android/Sdk`；Android 36、Build Tools 36.0.0、platform-tools 37.0.1、命令行工具已安装并由 sdkmanager 清单识别。
- Android Studio 自带 JBR：`D:/Android/AndroidStudio/jbr`，javac 25.0.4。未覆盖全局 JAVA_HOME，避免影响其他工程。
- 用户级 ANDROID_HOME 与 PATH 已配置，包含 Git、adb、sdkmanager。旧终端和已打开的应用需重启后继承新环境。
- 已验证 git 2.56.0.windows.4、adb、aapt2、javac；目前可走真机 USB 调试。没有安装模拟器系统镜像，没有改 BIOS / Windows 虚拟化功能或强制重启。
- 安装开发工具不等于已经移植 Android 客户端。桌面 PyQt 界面不能直接变成原生 Android APK；可复用账户 API / 云同步契约，移动端另做界面与权限适配。

## macOS（方案说明）

Windows 可以写跨端业务代码和 Swift 源码；苹果平台的最终 Xcode 编译、签名和真实验收需要 macOS。可使用实体 Mac、远程 Mac 或 macOS 构建机。官方系统要求：https://developer.apple.com/xcode/system-requirements

普通 Windows PC 上的 macOS 虚拟机不是苹果官方支持的开发路线。Apple macOS 许可中的虚拟化授权限定 Apple 品牌硬件，不能把普通 PC 虚拟机当成可可靠交付的正式构建环境。官方许可：https://www.apple.com/legal/sla/docs/macOSTahoe.pdf

当前 GitHub 已有 mac 目录的 SwiftUI 源码，随本次合并保留；未声称已生成或测试 DMG。建议 Windows 做 Android / 共用后端，Mac 真机或远程 Mac 做苹果端构建和签名。
