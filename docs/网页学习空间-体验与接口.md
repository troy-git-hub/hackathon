# 网页学习空间（2026-11-16）

本轮由两个会话合作：前端负责 `Echo Website/public/user.html`、`console.js`、新增 `study.js/css`；另一会话负责 `account-server`、解析器、计费、部署。现有账户登录、复习自评和单题练习保留。

## 用户路径

- **学习计划**：知识点复习、每日小题、每周考试提醒。时间固定北京时间；保存计划、打开页面不会触发模型。每日优先免费抽题，AI 生成是独立按钮并弹出计费确认。
- **资料与试卷**：上传原件 → 查看解析文字 → 免费校正 → 手动 AI 解析/提取题目 → 展开核对原题、参考答案与解析 → 免费确认加入题库。未确认题目不能用于免费抽题。扫描 PDF 不暗中做付费 OCR，可补充文字或上传单页图片后手动视觉解析。
- **考试机 Beta**：选来源 → 免费题库组卷或手动 AI 新组卷 → 自动保存答案 → 交卷 → 看解析。单选、多选、判断、填空、简答均有输入界面；选择答案是零起整数，多选是整数数组。主观题 pending 与最终判分分开显示，AI 批改由用户确认触发。

删除资料会移除在线原件、解析和关联题库；已开始和已交卷的试卷仍保留快照。文件限制、账户额度与 token 单价从服务端返回；前端同时提供大小预检，服务端仍为最终校验方。

## 作答恢复与费用保护

接口前缀为 `/api/account/me/study`。`/preferences` 后端合并更新；前端也合并当前偏好，避免每日题量变更重置每周安排。

`/attempts/{id}/answers` 使用服务端 revision，并在前端串行保存。编辑后 800ms 合并保存，提供手动保存与网络重试；409 不自动覆盖，而是提示重新载入服务端作答。浏览器会话内按账户隔离暂存未确认保存的草稿，用户可手动恢复；退出或切换账户清除旧账户缓存和已显示内容。服务端截止时间权威，超时获取服务端结算，不在浏览器伪造判分。

免费题库不足时显示服务端 409，不自动转成付费生成。AI 按钮使用 request_id；不明确的超时复用编号，避免重复扣点。明确拒绝后允许下一次用户操作重新请求。切屏、隐藏页面和退出全屏可在专注模式下记为事件；浏览器无法阻止系统切换，不宣传为强监考。
