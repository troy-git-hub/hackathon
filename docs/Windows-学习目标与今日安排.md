## 原生入口

主页“学习目标与今日安排”、用户中心同名按钮、设置“学习目标 · 兴趣与每日安排”。使用原生 Qt 表单、Echo 标题栏/图标/六皮肤，不嵌入网页。次级窗口只有关闭，目标保存按钮固定在底部。

账户登录且首次返回主页时检查一次目标，没有目标则打开设定；访客、离线待验证、ECHO_OFFLINE 不请求。每个登录身份仅检查一次，不循环网络重试。首次引导可关闭，后续通过上述入口修改。

## 数据与行为

- 新增 `echo/backend/learning_path.py`、`echo/widgets/learning_path.py`。没有另存一套本地目标/兴趣档案，复用账户令牌请求云端。
- GET `/v1/me/learning-path`；POST `/goal` 带 goal.revision；POST `/today` 带 day_plan.revision；POST `/reflections` 使用客户端 UUID，同一窗口修改后重复保存仍是同一记录。
- 目标：学科、4至160字具体目标、可选两年内日期、每日5/10/15/20/30/45分钟、图解/情境/简明讲解；兴趣最多5项及80字自由文本，保留旧 interest 和缺失 interests 的兼容。其他端保存的兴趣动态显示，可取消。
- 今日：复习已学/学习新知识，显示云端推荐与回想/练习/问题的独立状态，支持原生回想输入。北京时间跨日后先刷新，避免使用昨天的版本写入今天。
- 不自动生成课程、不自动创建或重复生成当日练习、不触发付费模型。此模块尚不提供完整课程生成或原生每日卷生成，复用现有练习/清卷功能。
- 409 保留输入并要求先手动刷新确认，没有自动覆盖或写入重试；刷新替换未保存目标前确认。保存每日选择/回想不覆盖未保存的目标输入。
- 请求捕获原账户令牌，发送前/接收后核对账户与会话；退出/换号丢弃结果、清空窗口的个人输入并关闭。网络失败保留原输入和登录态。
