# 考试机 Beta / echo.exam/1

从“我的小本”的章节或历史课堂知识点选择 1–12 项，生成 5/10/15/20 题完整综合卷，5–180 分钟。每道题带资料编号，校验全部来源覆盖；无效输出明确报错，不用假题填充。组卷通过用途 quiz 的账户 API 按 token 计费。

本地按账户哈希隔离试卷，原子存档，保留最近 30 张。选择/文字变化保存，重新打开继续；退出后计时继续。客观题本地评分，简答/填空保留待批改，不伪装为已判零分。该功能为 Beta。

防作弊可选，在考试设置勾选并记住选择：全屏、置顶、失焦日志和退出确认。可以正常退出并恢复；不能防止操作系统级工具、其他设备或用户直接查看本地文件。网页不能直接照搬桌面的置顶权限。

跨端契约：后端 exam.public_paper(paper) 产生 echo.exam/1 的题目视图，剔除 answer/explain；网页服务器必须独立持有完整试卷，在服务端验证账户、时限、交卷幂等并评分。尚未实现网页考试端点或云端同步考试，禁止将完整含答案的本地存档直接上传后公开。交给官网开发者接入此契约，不声称已上线。
