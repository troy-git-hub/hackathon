# 桌面界面调整（2026-11-16）

## 本轮改动

- 主页：双栏结构保留，内容宽 780；开课按钮 34px，次要入口和复习操作 28px；课程名称可选，说明改为短提示。复习卡使用较小的计数标题，预计时长与操作同排。“更多”默认收起，全部原功能仍可进入，移除“工具”字样。
- 小本、组卷、考试机、设置：新增共用自绘标题栏，采用当前 Echo 皮肤、右侧最小化和关闭、拖动和右下角调整大小。考试关闭仍经过原退出确认，保存失败仍可重试。登录窗也共用相同控制样式。
- 用户中心：拆出原生 `AccountCenter`，显示近期三节课、最近三条 AI 辅助与复习摘要。同步/关联/退出收在可展开区域。管理员网页入口只在设置显示，普通用户不可见，点击时再次检查角色。
- 资料页：头像与统计数字适当缩小，保持原画像、记忆、导出等功能。

原生 Windows 隔离渲染默认主页高度约 335px；内容和系统缩放变化时会自适应，并非硬裁切高度。有待复习、模型下载或更多入口展开时按内容增高。

## 账户和数据

用户中心异步读取已有 `GET /v1/me`、`/v1/me/workspace`、`/v1/me/requests`，不调用 AI。使用打开窗口时的会话令牌，返回结果时校验当前账户；部分请求失败保留可用内容并允许刷新。旧账户关联的本机资料不展示，账户变化后清除已显示摘要。同步操作沿用现有实现。

后端、网页、Android 清卷原生项目未修改。未打包或发布，此次交付是本机源码和检查结果。
