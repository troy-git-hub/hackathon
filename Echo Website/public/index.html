A FEW THINGS TO KNOW

开始之前。

支持哪些课程平台？

Echo 在 Windows 上捕捉系统播放的声音，适用于网课、会议和录播课程；戴耳机也可以使用。请确保你有权处理课程内容。

账户版与当前下载版本有什么区别？

已发布的 2.4.0 安装包需要自行配置模型。账户版源码已接入密码与验证码登录，在高级设置中可选择自己的模型 API；新版安装包尚未发布。

我的课程内容会被上传吗？

语音转写在本地运行。账户版使用云端 AI 时，相关文字和你确认附上的截图会经 Echo 账户 API 发送给模型提供商；回复会短时加密缓存，用于请求重试与防止重复扣点。本机测试版登录后默认同步个人学习档案与复习进度，可在用户中心暂停；不上传完整课程原文、录音、模型密钥或原始课件。公开 2.4.0 仍保留原来的本地流程，更新服务不接收学习资料。

如何更新 Echo？

2.4.0 起可在「设置 → 更新中心」检查版本、查看说明和下载。客户端会验证版本签名及安装包完整性，由你确认安装。
